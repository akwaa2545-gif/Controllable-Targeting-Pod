02 / SETUP

Install once. Configure first.

What you need

  • Nuclear Option 0.34.6 on Windows.
  • Official BepInEx 5.4.23.5 or 5.4.23.6, with its bundled Harmony 2.9.0.0.
  • A supported offline local cockpit. Multiplayer and spectator contexts are not supported.

Exact game and loader identities are checked. Other versions or rebuilt dependencies may be refused.

Official BepInEx setup ↗

Where are the settings?

Use the TGP config file or optional ConfigurationManager. The shared-panel preview shows a separate host integration, not a menu bundled in the standalone DLL.

Detailed settings tutorial ↗
  1. 01

    Close the game and back up

    Exit Nuclear Option completely. Back up your existing TGP DLL and its file in BepInEx/config. Install a supported BepInEx loader first if it is not already working.

  2. 02

    Copy the TGP DLL

    Download TargetingPodDisplay.dll and put it inside BepInEx/plugins/TargetingPodDisplay in your Nuclear Option folder. Create that subfolder if needed. No ZIP extraction is needed.

    Nuclear Option/
└─ BepInEx/
   └─ plugins/
      └─ TargetingPodDisplay/
         └─ TargetingPodDisplay.dll

    Keep exactly one copy of the TGP DLL. Remove duplicate older TGP copies from plugin subfolders; leave unrelated mods alone.

  3. 03

    Launch once and check the log

    Start the game, then check BepInEx/LogOutput.log for Targeting Pod Display 0.1.17. Missing or refused versions need fixing before you continue. Close the game before editing its generated config.

  4. 04

    Standalone setup

    With the game closed, open BepInEx/config/local.nuclearoption.targetingpoddisplay.cfg. Under [General], set Enabled = true. Under [Keys], assign Fullscreen and ScanFollow to distinct supported, unused keys. Optional ConfigurationManager provides settings controls too.

    TGP starts disabled: General.Enabled = false. Its Fullscreen, ScanFollow, InfraredToggle and PiPToggle shortcuts all start as None. F6 is not a default TGP shortcut.

  5. 05

    Close the menu and test gently

    Save your config, start the game and enter a supported offline cockpit. Release held controls before opening the view. Briefly stop mouse movement and scrolling before opening fullscreen. Try the camera in a safe offline situation. Keep your normal flight-view return key ready and check the log if a view refuses to open.

Where are my settings saved?

TGP uses BepInEx/config/local.nuclearoption.targetingpoddisplay.cfg. Preserve that file when updating. To edit it manually, close the game first. Fullscreen and other optional keys begin as None; configure them before using the view.

01 / OPEN SETTINGS

Choose your interface

Open your installed ConfigurationManager with its configured shortcut, then find Targeting Pod Display. Pause before editing bindings. ConfigurationManager is optional and is not included in the DLL.

Without a settings tool, close the game and edit BepInEx/config/local.nuclearoption.targetingpoddisplay.cfg. The same fields are available there.

The shared-panel image below is an integration layout preview. It requires an additional menu host: the standalone DLL does not create a shared F8 menu. If that integration is already installed, pause, open the host's Panel shortcut, then select TGP → Settings or Bindings.

02 / FIRST CONFIGURATION

Start with mouse scanning

  1. Set General → Enabled to true.
  2. Keep ReplaceCockpit off initially.
  3. Bind Fullscreen, then optionally ScanFollow and InfraredToggle.
  4. Keep FullscreenMouseSlew and FullscreenWheelZoom on.
  5. Leave ManualSensor unassigned for mouse-only use.
  6. Close settings, release inputs and test in an offline cockpit.

03 / EDIT A BINDING

Key only, Alone or Combine

  1. Select an action and click Bind.
  2. Key only: release held inputs and press a supported keyboard key.
  3. Special input → Alone: choose a mouse/Ctrl/Shift/Alt input, click Save, then release all inputs so it can commit.
  4. Special input → Combine: release inputs and press the ordinary keyboard main key without holding the selected special. During use, hold both.
  5. Read overlap warnings. Clear unbinds; Cancel/Escape keeps the previous binding; Back returns to the picker.

Shared-panel settings save immediately; no overall Apply button is required. A shared binding can still trigger native controls or another mod.

04 / PIP & COCKPIT

Choose what stays visible

Enable PiPEnabled for the small feed, and optionally assign PiPToggle or the held PiP zoom keys. PiP zoom works outside fullscreen with a visible live feed; holding both zoom keys cancels zoom.

ReplaceCockpit displays the owned feed in a supported target pane. The two hide settings change that pane's drawing, not its native targeting logic.

PiP is fixed at right-center, aspect-fitted within 28% screen width × 40% height, 16 pixels from the right edge. This build has no size, position, opacity or drag controls.

Optional keyboard sensor control

Bind ManualSensor, review all eight SensorKeys against the game and other mods, then set ConfirmNoOtherModUsesSensorKeys = true only after checking those inputs. Initial sensor keys: arrows to slew, PageUp/PageDown to zoom, Home to recenter and End for inertial direction hold.

This confirmation is not needed for mouse ScanFollow or PiP zoom. Fullscreen must still be bound separately.

Saving and recovering your settings

Preserve your config during upgrades. Close the panel and release both old/new inputs after changes; an active camera may close and need explicit reentry. If a binding becomes unusable, close the game and restore a supported unused plain key in the config, clearing its companion modifier entry if you intend a plain key.

Use the complete walkthrough for field-by-field explanations, capture behavior and troubleshooting.

04 / IN THE AIR

Get to know the controls.

Full TGP reference ↗
TGP / FIRST FLIGHT

A simple starting workflow

  1. Enable TGP and set a Fullscreen shortcut.
  2. Enter the supported cockpit view, then open TGP fullscreen with your assigned key.
  3. Use ScanFollow to choose Scan. With fullscreen mouse slew enabled, move the mouse to look around and use the wheel to zoom.
  4. Use the game's normal Select action to add targets. Explicit Scan keeps those selections while you keep searching.
  5. Press ScanFollow again to follow the selected target/group. With no selected targets, Scan remains active.
  6. Use your Fullscreen shortcut to return. Camera state is remembered only within the same valid aircraft/session.
BINDINGS / YOUR CHOICE

Set a shortcut

Standalone: edit the TGP config while the game is closed, or use optional ConfigurationManager. If a compatible shared menu host is installed, pause and open its TGP → Bindings page. In a supported binding editor, select an action, then Bind.

  • Key only: capture an ordinary keyboard key.
  • Special input: select a mouse button or Ctrl/Shift/Alt, then choose Alone or Combine. Combine waits for a keyboard key.
  • Clear unbinds. Cancel keeps the previous value. Release held controls before confirming and resuming.

Recognized overlaps show warnings. A shared button can still fire, pan or select in the game. Rebinding does not globally suppress native controls.

06 / FIELD NOTES

A few things to know.

Start with the TGP DLL, a supported game/loader and an offline cockpit.

Report an issue ↗
The menu or fullscreen will not open

Check the startup versions, duplicate DLLs and compatibility messages in BepInEx/LogOutput.log. For standalone settings, use an installed ConfigurationManager or edit the config with the game closed. A shared F8 menu needs an additional host. TGP must be enabled and Fullscreen bound separately. Release held controls; after startup or a config change, a native input update may be needed before retrying.

What do AREA, NO GROUND and GIMBAL LIMIT mean?

AREA is a valid fixed-ground reference in Scan, not moving-target tracking or weapon lock. NO GROUND means supported terrain was not acquired. MASKED means obstruction. GIMBAL LIMIT means the manual viewing stop is reached: normal Scan allows up to 135° left/right of the nose and blocks the rear 90° sector. Unknown extra equipment does not unlock a wider range.

Is IR a thermal camera? Are target symbols a lock?

IR (GAME) uses the game's infrared presentation, not temperature-based thermal sensing. Red diamonds show known hostiles; white brackets mark native selection. Cyan squares represent known friendlies. These are not proof of optical visibility or seeker lock. Range/grid and weapon advice labeled SEL refer to native selected targets, not necessarily the reticle's ground point.

How do I update or uninstall?

Close the game. Back up the TGP DLL and config, then replace the DLL once. Keep your config settings. To uninstall TGP, remove only TargetingPodDisplay.dll from BepInEx/plugins while the game is closed. Leave other mods alone. Keep config backups if you may reinstall.

What should I include in a bug report?

Include game and BepInEx versions, the TGP version and any optional companion version, the exact action and warning, reproduction steps, and relevant log excerpts. Review logs for personal paths or other private information before posting publicly. The settings walkthrough and TGP smoke checklist describe checks still needed in game.
