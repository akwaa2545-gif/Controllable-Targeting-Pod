02 / SETUP

Install once. Configure first.

What you need

  • Nuclear Option 0.34.6 on Windows.
  • Official BepInEx 5.4.23.5 or 5.4.23.6, with its bundled Harmony 2.9.0.0.
  • A supported offline local cockpit. Multiplayer and spectator contexts are not supported.

Exact game and loader identities are checked. Other versions or rebuilt dependencies may be refused.

Official BepInEx setup ↗

Is Observer required?

No, for core TGP. Observer 0.5.7 hosts the shared in-game settings menu and adds paired features, including optional Flight Hold. Standalone TGP uses its config file or optional ConfigurationManager.

  1. 01

    Close the game and back up

    Exit Nuclear Option completely. Back up your existing Observer/TGP DLLs and their files in BepInEx/config. Install a supported BepInEx loader first if it is not already working.

  2. 02

    Extract and copy the DLLs

    Download the runtime ZIP and extract it. Put TargetingPodDisplay.dll and, for the matched setup, Observer.dll inside BepInEx/plugins in your Nuclear Option folder.

    Nuclear Option/
└─ BepInEx/
   └─ plugins/
      ├─ TargetingPodDisplay.dll
      └─ Observer.dll

    Keep exactly one copy of each DLL. Remove duplicate older copies from plugin subfolders. Do not put the ZIP itself in plugins.

  3. 03

    Launch once and check the log

    Start the game, then check BepInEx/LogOutput.log for Targeting Pod Display 0.1.17 and, if installed, Observer 0.5.7. Missing or refused versions need fixing before you continue.

  4. 04

    Enable TGP and bind your controls

    In a supported offline cockpit, press Esc to pause, then F8 (Observer's default Panel key). Choose TGP → Settings and set Enabled to true. In TGP → Bindings, assign unused keys to Fullscreen, ScanFollow and the optional actions you want.

    TGP starts disabled: General.Enabled = false. Its Fullscreen, ScanFollow, InfraredToggle and PiPToggle shortcuts all start as None. F6 is not a default TGP shortcut.

  5. 05

    Close the menu and test gently

    Release held controls, close the mod menu, then press Esc to resume. Briefly stop mouse movement and scrolling before opening fullscreen. Try the camera in a safe offline situation. Keep your normal flight-view return key ready and check the log if a view refuses to open.

Standalone TGP or manual configuration

Close the game before editing BepInEx/config/local.nuclearoption.targetingpoddisplay.cfg. Set Enabled = true under [General] and assign supported, unused keys under [Keys]. Optional ConfigurationManager offers the same settings. Keep existing configs when updating; the ZIP's config files are examples, not replacements.

Observer's config is BepInEx/config/io.github.nuclearoption.observer.cfg. If you clear its menu shortcut, restore Panel = F8 under [Keys] with the game closed, or use ConfigurationManager.

Full TGP reference ↗
TGP / FIRST FLIGHT

A simple starting workflow

  1. Enable TGP and set a Fullscreen shortcut.
  2. Enter the supported cockpit view, then open TGP fullscreen with your assigned key.
  3. Use ScanFollow to choose Scan. With fullscreen mouse slew enabled, move the mouse to look around and use the wheel to zoom.
  4. Use the game's normal Select action to add targets. Explicit Scan keeps those selections while you keep searching.
  5. Press ScanFollow again to follow the selected target/group. With no selected targets, Scan remains active.
  6. Use your Fullscreen shortcut to return. Camera state is remembered only within the same valid aircraft/session.
BINDINGS / YOUR CHOICE

Set a shortcut

Pause → F8 → TGP → Bindings. Select an action, then Bind.

  • Key only: capture an ordinary keyboard key.
  • Special input: select a mouse button or Ctrl/Shift/Alt, then choose Alone or Combine. Combine waits for a keyboard key.
  • Clear unbinds. Cancel keeps the previous value. Release held controls before confirming and resuming.

Recognized overlaps show warnings. A shared button can still fire, pan or select in the game. Rebinding does not globally suppress native controls.

Optional keyboard sensor controls

For the separate ManualSensor path, the initial sensor keys are arrow keys for slew, PageUp/PageDown for zoom, Home for recenter and End for inertial direction hold. They are not a ready-to-use default fullscreen binding. Configure ManualSensor and check all eight keys for native/other-mod conflicts before setting ConfirmNoOtherModUsesSensorKeys.

Mouse ScanFollow does not require ManualSensor or the eight-key confirmation.

Observer default shortcuts

F8 Settings panel, while paused in a supported cockpit

F9 Toggle missile PiP

F10 Next missile

F11 Missile fullscreen

F7 Reset orbit

Left Ctrl + left-click a missile on the map to Watch

These are Observer shortcuts, not TGP defaults. You can change them in Observer → Bindings. Automatic own-launch viewing and Flight Hold are separate opt-ins and start off.

Flight Hold is optional and experimental. If missile fullscreen says AUTO HOLD INACTIVE / AIRCRAFT NOT STABILIZED, the aircraft is not being stabilized. Exit fullscreen to fly. With Auto Hold enabled, supported map/TGP views exclude virtual-stick mouse steering; keyboard/controller input cancels Hold. Direct Mouse Pitch/Roll/Yaw bindings are unsupported. Read the paired release guide before using it.

05 / FIELD NOTES

A few things to know.

Start with the exact matched DLLs, a supported game/loader and an offline cockpit.

Report an issue ↗
The menu or fullscreen will not open

Check the startup versions, duplicate DLLs and compatibility messages in BepInEx/LogOutput.log. For the shared menu, install Observer 0.5.7, pause in a supported cockpit with Esc, then press its Panel key (default F8). TGP must be enabled and Fullscreen bound separately. Release held controls; after startup or a config change, a native input update may be needed before retrying.

What do AREA, NO GROUND and GIMBAL LIMIT mean?

AREA is a valid fixed-ground reference in Scan, not moving-target tracking or weapon lock. NO GROUND means supported terrain was not acquired. MASKED means obstruction. GIMBAL LIMIT means the manual viewing stop is reached: normal Scan allows up to 135° left/right of the nose and blocks the rear 90° sector. Unknown extra equipment does not unlock a wider range.

Is IR a thermal camera? Are target symbols a lock?

IR (GAME) uses the game's infrared presentation, not temperature-based thermal sensing. Red diamonds show known hostiles; white brackets mark native selection. Cyan squares represent known friendlies. These are not proof of optical visibility or seeker lock. Range/grid and weapon advice labeled SEL refer to native selected targets, not necessarily the reticle's ground point.

How do I update or uninstall?

Close the game. Back up both DLLs and configs, then replace each DLL once with the matched release. Keep your config settings; do not overwrite them with examples. To uninstall these mods, remove only their DLLs from BepInEx/plugins while the game is closed. Keep config backups if you may reinstall.

What should I include in a bug report?

Include game and BepInEx versions, both mod versions, the exact action and warning, reproduction steps, and relevant log excerpts. Review logs for personal paths or other private information before posting publicly. The paired smoke checklist and TGP smoke checklist describe checks still needed in game.
